# SkillPath — แพลตฟอร์มเต็มรูปแบบ

ต่อยอดจากต้นแบบหน้าเดียวของทีม 4WARDERS ([chonnaveesuk.github.io/skillpath/v1](https://chonnaveesuk.github.io/skillpath/v1/)) ให้ครบตั้งแต่ทางเข้าจนถึงรายละเอียดของ SkillPath — ยังคงเป็น HTML + CSS + JS ธรรมดา ไม่มี build step เปิดจากไฟล์หรือรันเว็บเซิร์ฟเวอร์แบบไหนก็ได้ ตามแนวทางเดิมของทีม

## หน้าทั้งหมด

| หน้า | หน้าที่ |
|---|---|
| `index.html` | ทางเข้า — อธิบายปัญหา (หลักสูตร vs ตลาดงาน ใช้คนละคำ) พร้อม CTA เข้าสู่แอป |
| `onboarding.html` | ตั้งโปรไฟล์ 4 ขั้นตอน: สาขา → เป้าหมายอาชีพ (ไม่บังคับ) → ปี/เทอมปัจจุบัน + ปรับแต่งรายวิชาเอง → สรุป |
| `app.html` | สำรวจอาชีพ + ดูแผนรายวิชา — เดิมคือหน้าเดียวของต้นแบบ v1 ตอนนี้ทุกเปอร์เซ็นต์อ่านจากโปรไฟล์จริงของผู้ใช้ |
| `curriculum.html` | เบราว์เซอร์ทั้งหลักสูตร ทีละวิชา — ยกระดับ insight ระดับอาชีพของต้นแบบเดิมมาดูทั้งหลักสูตรพร้อมกัน |
| `about.html` | ปัญหา วิธีคำนวณ ขอบเขตข้อมูล และทิศทางถัดไป (เนื้อหาอ้างอิงจาก README ต้นฉบับ) |

โครงสร้างข้อมูล (`SK`, `COURSES`, `ROLES`, `DEMAND`, `POSTS`) ทั้งหมดคงตัวเลข/ถ้อยคำจากต้นแบบ v1 ไว้ทุกตัว ไม่ได้แต่งข้อมูลใหม่ — ส่วนที่เพิ่มคือ **เอนจินโปรไฟล์แบบไดนามิก** (`assets/data.js`) ที่คำนวณสถานะทักษะจากปี/เทอมที่ผู้ใช้เลือกจริง แทนการฝังค่า "ปี 3 เทอม 1" ตายตัวไว้ในโค้ด

### เพิ่มล่าสุด — เน้นกลุ่มนักศึกษา (สังเคราะห์จาก `SkillPath_PitchDeck_1.pdf`)

- **เป้าหมายอาชีพในโปรไฟล์** — onboarding ถามว่าอยากทำงานอะไร (เลือกได้/ข้ามได้) แล้ว `app.html` เปิดตำแหน่งนั้นเป็นค่าเริ่มต้นแทนตำแหน่งที่ครอบคลุมสูงสุด พร้อมป้าย "เป้าหมายของคุณ" ในรายการอาชีพ
- **แผงความน่าเชื่อถือ + ฟีดแบ็ก** — ทุกทักษะที่กดดูหลักฐาน (ในหน้าสำรวจอาชีพและหลักสูตร) มีคำอธิบายวิธีจับคู่ข้อมูล และปุ่ม "ตรง / ไม่ตรง" ให้ผู้ใช้ยืนยันว่าคำแนะนำตรงกับที่เจอจริงไหม — เก็บใน localStorage ปิดลูป Human-in-the-loop ที่ deck ระบุไว้
- **งานวิจัยผู้ใช้บนหน้าแรก** — สถิติจากการสัมภาษณ์นักศึกษา 13 คน (70% ไม่มั่นใจสิ่งที่เตรียมตัวอยู่) และเรื่องราวของ "เนเน่" นักศึกษาปี 2 ที่อยากเป็น Data Analyst แต่หาเส้นทางไม่เจอ — ทั้งหมดอยู่ใน `RESEARCH` constant ของ `assets/data.js`

## โครงสร้างไฟล์

```
index.html          ทางเข้า
onboarding.html      ตั้งโปรไฟล์
app.html             สำรวจอาชีพ + แผนของฉัน
curriculum.html       เบราว์เซอร์หลักสูตร
about.html            เกี่ยวกับ / วิธีคำนวณ
assets/
  style.css           ดีไซน์ระบบร่วมทุกหน้า (โทนสี ฟอนต์ คอมโพเนนต์)
  data.js              ข้อมูลจริง + เอนจินคำนวณโปรไฟล์ + ตัวช่วย render nav
```

## รันเดโม

เปิด `index.html` ในเบราว์เซอร์ได้โดยตรง (ไม่ต้องมี server) หรือถ้าต้องการรันผ่าน local server:

```bash
python -m http.server 8843
```

แล้วเปิด `http://localhost:8843/index.html`

## ขอบเขตข้อมูล (เหมือนต้นแบบ v1 ทุกประการ)

- **หลักสูตร = เอกสารจริง** — วท.บ. วิทยาการคอมพิวเตอร์ (ปรับปรุง พ.ศ. 2566) คณะวิทยาศาสตร์และเทคโนโลยี มหาวิทยาลัยธรรมศาสตร์
- **ประกาศงาน = ชุดข้อมูลตัวอย่าง** สำหรับสาธิต UI เท่านั้น ยังไม่ใช่ผลจากการวิเคราะห์ประกาศงานจริง
